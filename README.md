# Madhireddy Narasimha Reddy — Portfolio

A responsive red-and-black portfolio with a cinematic opening screen. Visitors first see the supplied profile portrait and a **CHECK MY PORTFOLIO** button. Clicking it reveals the full portfolio.

## Run locally
1. Extract the ZIP file.
2. Open the `aiml-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No framework, build step, or package installation is required.

## Project files
- `index.html` — intro screen and portfolio content.
- `css/style.css` — layout, responsive styling, red lighting and transitions.
- `js/script.js` — intro button, mobile navigation and scroll reveal effects.
- `assets/profile.png` — the profile portrait supplied for this portfolio.
- `W.CV.pdf` — resume linked from the portfolio.

## Personalise
Update the text, skills, project details, email address and social profile links in `index.html`. Replace `assets/profile.png` with another image using the same filename if you want to change the portrait.
